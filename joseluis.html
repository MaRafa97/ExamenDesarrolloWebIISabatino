Tu reto

Debajo de este panel hay una tarjeta de perfil construida con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízala por completo usando la IA como asistente y cumple los tres requisitos siguientes.

1. API a consumir

Dog API
Endpoint sugerido: https://dog.ceo/api/breeds/image/random/9

2. Temática visual a exigir a la IA

Glassmorphism: fondos translúcidos, efecto de vidrio esmerilado sobre fondos oscuros.

3. Misión interactiva: Visor de Galería Ampliada

Visual: grid de fotos pequeñas que, al hacer clic, muestran su versión en pantalla completa.

Lógica exclusiva: la caja ampliada debe mostrar exactamente la imagen en la que se hizo clic.

Tip de prompting

"En Vue 3, necesito una variable que almacene la URL de la imagen seleccionada. Al hacer clic, asigna su URL a la variable y usa un modal con v-if para renderizarla grande."
