Tu misión en una frase

Convierte esta tarjeta fea en un directorio de cervecerías con estilo Steampunk y un buscador que filtra mientras escribes.

Antes de empezar

Debajo de este panel hay una tarjeta hecha "a la antigua": está fea a propósito y su código está lleno de malas prácticas. Tu trabajo es rehacerla desde cero para que se vea profesional. La IA es tu asistente: pídele ayuda, pero tú decides cómo se ve.

Vas a usar dos herramientas, sin instalar nada:

  • Tailwind CSS te deja diseñar escribiendo clases directamente en el HTML, como bg-pink-200 (fondo rosa) o rounded-xl (esquinas redondeadas). Es como aplicar estilos en Figma, pero con palabras.
  • Vue hace que tu página reaccione a lo que hace la persona (clics, escritura, mouse) y se encarga de mostrar los datos que llegan de internet.

Importante: no borres este panel. Tu página nueva va debajo de él.

Paso 2 · Muestra datos reales de Open Brewery DB

Buena noticia: los datos ya llegan solos. Al final de este archivo hay un bloque llamado CONEXIÓN A LA API que trae una lista de cervecerías de todo el mundo. No necesitas entenderlo ni cambiarlo: solo consérvalo en tu página.

Para pedir los datos se usa await obtenerCervecerias(). Cada cervecería trae esta información:

Llegan 20 cervecerías; puedes pedir más, por ejemplo obtenerCervecerias(50).

Si la API falla, verás datos de ejemplo y un aviso en la consola del navegador. No es tu culpa: sigue diseñando con ellos.

Paso 3 · Agrega la interacción: Buscador instantáneo

Cómo se ve: Una barra de búsqueda encima de la lista de tarjetas.

Cómo funciona: Con cada letra que escribes, las tarjetas que no coinciden desaparecen al momento, sin presionar Enter.

Piénsalo como: buscar un contacto en tu celular: con cada letra la lista se va haciendo más corta.

Tu punto de partida (copia y pega)

Este es el esqueleto mínimo. Borra la tarjeta fea y arma tu página con estas cuatro partes, cada una en el lugar que indica su letra (A, B, C y D). Con eso los datos ya aparecen en pantalla; a partir de ahí, diseña.

<!-- A) Dentro de <head>: las dos herramientas -->
<script src="https://cdn.tailwindcss.com/3.4.17"></script>
<script src="https://unpkg.com/vue@3.5.13/dist/vue.global.prod.js"></script>

<!-- B) En <body>, debajo de este panel: tu diseño -->
<div id="app">
  <p v-for="cerveceria in cervecerias" :key="cerveceria.id" class="font-mono">{{ cerveceria.nombre }}</p>
</div>

<!-- C) Aquí va el bloque "CONEXIÓN A LA API" (ya está al final de este archivo) -->

<!-- D) Al final de todo: tu código de Vue -->
<script>
  const { createApp, ref, onMounted } = Vue;

  createApp({
    setup() {
      const cervecerias = ref([]);

      onMounted(async () => {
        cervecerias.value = await obtenerCervecerias();
      });

      return { cervecerias };
    },
  }).mount('#app');
</script>

Hola. Soy estudiante de diseño y estoy aprendiendo a programar. Tengo una página HTML que usa Vue 3 y Tailwind CSS cargados desde CDN (no puedo instalar nada). Ya tengo una función llamada obtenerCervecerias() que me regresa una lista de cervecerías; cada una tiene nombre, tipo, ciudad, estado, pais y sitioWeb. Ayúdame a crear, dentro de <div id="app">, un diseño estilo Steampunk / Industrial: como una máquina antigua de vapor: grises metálicos, cobre, dorado apagado y letras tipo máquina de escribir. La página debe tener una barra de búsqueda encima de una lista de tarjetas que, con cada letra que se escribe, oculta al momento las tarjetas que no coinciden, sin presionar Enter. Dame el código completo y explícame cada parte con palabras sencillas, como si yo no supiera programar.

Tip del profe: "En Vue 3, tengo un arreglo y un input con v-model. Necesito una propiedad computada (computed) que filtre el arreglo original en tiempo real."

¿Cómo sé que terminé?

  • Borraste la tarjeta fea y en su lugar hay un diseño nuevo hecho con Tailwind: sin tablas para acomodar cosas, sin etiquetas viejas como <font> o <center> y sin style="..." dentro de las etiquetas.
  • La página se ve claramente Steampunk / Industrial.
  • Se muestran cervecerías reales que llegan de la API, no texto inventado.
  • La lista se filtra con cada letra, sin presionar Enter.
  • Funciona abriendo el archivo con doble clic, sin instalar nada.

Mini diccionario (por si una palabra te suena rara)
  • API: un servicio en internet que te manda datos (películas, clima, fotos) para mostrarlos en tu página.
  • CDN: una forma de usar una herramienta pegando una sola línea en tu HTML, sin instalar nada.
  • Clase de Tailwind: una palabra que aplica un estilo. Por ejemplo, p-4 agrega relleno y text-center centra el texto.
  • ref: una cajita donde Vue guarda un dato que puede cambiar. Cuando cambia, la página se actualiza sola.
  • {{ }}: dentro del HTML, muestra el valor de un dato. Por ejemplo, {{ cerveceria.nombre }}.
  • v-for: repite un elemento por cada dato de una lista (por ejemplo, una tarjeta por cada elemento).
  • v-if: muestra un elemento solo si se cumple una condición.
  • @click: indica qué pasa cuando alguien hace clic. También existen @mouseenter y @mouseleave para el mouse.
  • await: le dice al código "espera a que lleguen los datos antes de seguir".
