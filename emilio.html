Tu reto

Debajo de este panel hay un dashboard construido con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízalo por completo usando la IA como asistente y cumple los tres requisitos siguientes.

1. API a consumir

Open Brewery DB
Endpoint sugerido: https://api.openbrewerydb.org/v1/breweries?per_page=20

2. Temática visual a exigir a la IA

Steampunk / Industrial: grises metálicos, cobre, dorado apagado, tipografía tipo máquina de escribir.

3. Misión interactiva: Buscador Instantáneo

Visual: barra de búsqueda sobre una lista de tarjetas.

Lógica exclusiva: con cada letra escrita, las tarjetas que no coincidan desaparecen, sin necesidad de presionar Enter.

Tip de prompting

"En Vue 3, tengo un arreglo y un input con v-model. Necesito una propiedad computada (computed) que filtre el arreglo original en tiempo real."
