Tu reto

Debajo de este panel hay una tarjeta de perfil construida con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízala por completo usando la IA como asistente y cumple los tres requisitos siguientes.

Herramientas obligatorias: Vue 3 y Tailwind CSS, cargados solo por CDN (sin npm ni procesos de build).

1. API a consumir

Studio Ghibli API
Endpoint sugerido: https://ghibliapi.vercel.app/films

2. Temática visual a exigir a la IA

Kawaii / Pastel: colores suaves rosas y mentas, bordes muy redondeados, sombras difuminadas.

3. Misión interactiva: Acordeón de FAQs

Visual: lista de rectángulos apilados verticalmente con el texto colapsado.

Lógica exclusiva: al hacer clic en el Título 1, se expande. Nunca puede haber dos cajones abiertos: si abres el 2, el 1 se cierra solo.

Tip de prompting

"En Vue 3, tengo una lista de 3 tarjetas. Necesito una variable reactiva que guarde el ID de la tarjeta activa. Al hacer clic, actualiza la variable y usa v-if para mostrar solo el contenido que coincida."
