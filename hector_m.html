Tu reto

Debajo de este panel hay un dashboard construido con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízalo por completo usando la IA como asistente y cumple los tres requisitos siguientes.

Herramientas obligatorias: Vue 3 y Tailwind CSS, cargados solo por CDN (sin npm ni procesos de build).

1. API a consumir

RestCountries API
Endpoint sugerido: https://restcountries.com/v3.1/all?fields=name,flags,capital,population
Nota: el parámetro fields es obligatorio en el endpoint /all.

2. Temática visual a exigir a la IA

Material Design Clásico: colores sólidos índigo y ámbar, sombras de elevación.

3. Misión interactiva: Deslizador de Tarjetas (Slider)

Visual: bloque con flechas a la izquierda y a la derecha.

Lógica exclusiva: se ve un elemento a la vez. Debe ser cíclico: al pasar el último, vuelve al primero.

Tip de prompting

"En Vue 3, necesito una variable numérica como índice. Los botones suman o restan 1. Asegúrate de incluir la lógica matemática para que vuelva a cero si llega al final."
