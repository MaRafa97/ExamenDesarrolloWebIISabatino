Tu reto

Debajo de este panel hay una tarjeta de perfil construida con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízala por completo usando la IA como asistente y cumple los tres requisitos siguientes.

Herramientas obligatorias: Vue 3 y Tailwind CSS, cargados solo por CDN (sin npm ni procesos de build).

1. API a consumir

Bored API
Endpoint sugerido: https://bored-api.appbrewery.com/random
Nota: el dominio original (boredapi.com) ya no existe; usa esta versión espejo con la misma estructura de datos.

2. Temática visual a exigir a la IA

Orgánico / Naturaleza: tonos tierra, verdes desaturados, beige, tipografías con serifas.

3. Misión interactiva: Ventana Modal de Seguridad

Visual: rectángulo central que bloquea el fondo.

Lógica exclusiva: dentro del modal hay un input. El botón Confirmar se activa SOLO si escribes exactamente CONFIRMAR.

Tip de prompting

"En Vue 3, necesito una variable conectada a un input (v-model) que evalúe si la palabra es exactamente CONFIRMAR para remover el atributo disabled de un botón."
