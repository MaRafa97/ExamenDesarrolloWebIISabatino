Tu reto

Debajo de este panel hay una tarjeta de perfil construida con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízala por completo usando la IA como asistente y cumple los tres requisitos siguientes.

1. API a consumir

The Cat API
Endpoint sugerido: https://api.thecatapi.com/v1/images/search?limit=10

2. Temática visual a exigir a la IA

Brutalismo Web: alto contraste, rojo sobre azul, bordes negros gruesos, sombras sólidas.

3. Misión interactiva: Notificación Flotante (Toast)

Visual: tarjeta de alerta que flota en una esquina de la pantalla.

Lógica exclusiva: al hacer clic en un botón, la notificación aparece. Desaparece sola tras 3 segundos.

Tip de prompting

"En Vue 3, necesito una variable booleana para mostrar una notificación con v-if. Al dar clic cambia a true y, usando setTimeout de JS, vuelve a false en 3 segundos."
