Tu reto

Debajo de este panel hay una tarjeta de perfil construida con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízala por completo usando la IA como asistente y cumple los tres requisitos siguientes.

Herramientas obligatorias: Vue 3 y Tailwind CSS, cargados solo por CDN (sin npm ni procesos de build).

1. API a consumir

PokeAPI
Endpoint sugerido: https://pokeapi.co/api/v2/pokemon?limit=10

2. Temática visual a exigir a la IA

Pop Art / Cómic: rojo y amarillo estilo cómic, tramas de puntos, composición asimétrica.

3. Misión interactiva: Switch Tema Claro/Oscuro

Visual: botón tipo pastilla que imita un interruptor físico (toggle).

Lógica exclusiva: al encenderlo, cambian simultáneamente los colores de todo el contenedor principal.

Tip de prompting

"En Vue 3, necesito una variable booleana vinculada a un input checkbox. Usa binding dinámico (:class) en el contenedor principal para aplicar las clases oscuras si es verdadera."
