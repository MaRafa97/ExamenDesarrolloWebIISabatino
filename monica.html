Tu reto

Debajo de este panel hay una tarjeta de perfil construida con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízala por completo usando la IA como asistente y cumple los tres requisitos siguientes.

Herramientas obligatorias: Vue 3 y Tailwind CSS, cargados solo por CDN (sin npm ni procesos de build).

1. API a consumir

Art Institute of Chicago API
Endpoint sugerido: https://api.artic.edu/api/v1/artworks?limit=12&fields=id,title,artist_display,image_id

2. Temática visual a exigir a la IA

Art Deco: dorado, negro profundo, bordes delgados, altamente geométrico.

3. Misión interactiva: Sistema de Cargar Más

Visual: lista recortada con un botón abajo para descubrir el resto.

Lógica exclusiva: se muestran 2 elementos al inicio. Al presionar el botón aparecen 2 más, sin borrar los anteriores.

Tip de prompting

"En Vue 3, necesito una variable numérica (limite) que empiece en 2. Usa array.slice en el v-for de la plantilla HTML. El botón solo suma 2 a la variable limite."
