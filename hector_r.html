Tu reto

Debajo de este panel hay una tarjeta de perfil construida con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízala por completo usando la IA como asistente y cumple los tres requisitos siguientes.

1. API a consumir

D&D 5e API
Endpoint sugerido: https://www.dnd5eapi.co/api/2014/monsters

2. Temática visual a exigir a la IA

Vampírico / Gótico: carmesí oscuro, negro, tipografía con serifas afiladas.

3. Misión interactiva: Tooltips Contextuales

Visual: globo de texto pequeño que flota al pasar el mouse.

Lógica exclusiva: al pasar el ratón aparece el globo. Al salir, desaparece inmediatamente.

Tip de prompting

"En Vue 3, necesito controlar la visibilidad de un div flotante usando variables reactivas con los eventos nativos de Vue @mouseenter y @mouseleave."
