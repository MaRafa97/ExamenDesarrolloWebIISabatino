Tu reto

Debajo de este panel hay un dashboard construido con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízalo por completo usando la IA como asistente y cumple los tres requisitos siguientes.

Herramientas obligatorias: Vue 3 y Tailwind CSS, cargados solo por CDN (sin npm ni procesos de build).

1. API a consumir

SpaceX API
Endpoint sugerido: https://api.spacexdata.com/v4/launches/latest

2. Temática visual a exigir a la IA

Cyberpunk Neón: fondo muy oscuro, acentos magenta y cian, bordes rectos.

3. Misión interactiva: Sistema de Pestañas (Tabs)

Visual: menú horizontal y un contenedor de contenido debajo.

Lógica exclusiva: al hacer clic en otra pestaña, el contenido cambia instantáneamente sin recargar. Solo el contenido seleccionado existe en el DOM.

Tip de prompting

"En Vue 3, necesito una variable reactiva que almacene el nombre de la pestaña actual. Usa v-if para renderizar solo la sección que coincida."
