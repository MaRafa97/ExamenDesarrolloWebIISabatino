Debajo de este panel hay un dashboard construido con muy malas prácticas: tablas para maquetar, etiquetas obsoletas, estilos en línea y JavaScript antiguo. Refactorízalo por completo usando la IA como asistente y cumple los tres requisitos siguientes.

1. API a consumir

Open-Meteo
Endpoint sugerido: https://api.open-meteo.com/v1/forecast?latitude=19.43&longitude=-99.13&current=temperature_2m,wind_speed_10m

2. Temática visual a exigir a la IA

Corporativo Minimalista: monocromático azul, mucho espacio en blanco, sin sombras.

3. Misión interactiva: Menú Sidebar

Visual: panel lateral escondido fuera de la pantalla.

Lógica exclusiva: al presionar "Abrir Menú", el panel se desliza al centro. Debe tener un botón de cierre o cerrarse al hacer clic fuera de él.

Tip de prompting

"En Vue 3, necesito una variable booleana que controle la clase CSS de desplazamiento (translate-x) de un contenedor. Un botón alterna el estado para deslizarlo."
